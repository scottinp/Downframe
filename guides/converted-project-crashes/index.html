After Effects crashes when opening a converted project

The usual cause is a third-party plugin effect, such as Sapphire or Universe. Plugins save their own data in the project, and an older version of the plugin can crash After Effects instead of showing an error. Built-in effects don't do this.

Find the plugins

Drop the project into the converter. Before you convert, it lists every third-party effect the project uses, so you know which ones to look at.

Avoid the crash

  1. If you or someone else has the newer After Effects, disable or remove those effects there, save, and convert that file.
  2. Install the same plugin version on your computer if you can.
  3. Save your other open work before opening the converted project, in case it crashes.

Not a crash, just an error?

If After Effects shows a message instead of crashing, the project may use an effect or feature your version doesn't have. Converting changes the version stamp; it can't add what your version is missing.
