Konversi satu paket preset sekaligus

Seret seluruh folder ke konverter, pilih versi After Effects Anda, lalu unduh semuanya sebagai satu .zip. Tidak perlu memilah file dulu.

Apa saja yang masuk ke .zip

  • Dikonversi: preset dan proyek yang disimpan di versi lebih baru.
  • Disertakan apa adanya: file yang sudah bisa dibuka di versi Anda.
  • Dibiarkan apa adanya: file yang tidak bisa dikonversi Downframe, misalnya preset dari versi yang belum dikenali, atau proyek dengan track matte dari layer lain (2023) yang dikonversi ke 2022 atau lebih lama.
  • Tidak disertakan: file yang bukan preset atau proyek. Masing-masing ditampilkan beserta alasannya.

Nama .zip-nya mengikuti versi Anda, misalnya downframe-ae25.zip. Satu file akan diunduh sendiri, misalnya name.ae25.ffx.

Sebelum mengonversi

  • Tambah file dengan "+ Add files", atau hapus satu dengan ×.
  • Preset .ffx dan proyek .aep bisa dicampur.
  • Maksimal 500 MB per file dan 1 GB per batch, karena semuanya tetap di browser Anda.
