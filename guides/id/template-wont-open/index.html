Template After Effects yang diunduh tidak bisa dibuka?

Kebanyakan template disimpan di After Effects terbaru, jadi versi lama menolaknya dengan pesan "created with a newer version of After Effects". Konversi file .aep template ke versi Anda dengan Downframe lalu buka salinannya.

Langkah-langkah

  1. Ekstrak file unduhan template. Proyeknya adalah file .aep di dalamnya, biasanya di sebelah folder footage atau aset.
  2. Seret .aep ke konverter lalu pilih versi After Effects Anda.
  3. Simpan salinannya di folder yang sama dengan file asli, supaya link footage tetap jalan, lalu buka.

Kalau masih tidak jalan

  • Plugin yang dibutuhkan. Template sering butuh plugin (biasanya tercantum di halaman produk). Downframe menampilkan efek pihak ketiga sebelum mengonversi. Plugin yang lebih lama atau tidak ada bisa membuat After Effects crash. Apa yang harus dilakukan.
  • Font atau footage hilang. Ini tidak ada hubungannya dengan versi. After Effects akan memberi tahu font mana yang hilang, dan footage bisa di-relink lewat File → Dependencies.
  • Fitur yang lebih baru. Kalau template memakai sesuatu yang tidak ada di versi Anda, itu tidak akan muncul.
  • Bukan .aep. Downframe hanya mengonversi proyek .aep dan preset .ffx.
