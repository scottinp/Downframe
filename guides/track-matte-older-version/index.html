Track mattes and After Effects 2022 or older

After Effects 2023 changed track mattes: any layer in the comp can be picked as a matte. Before that, the matte had to be the layer directly above. 2022 and 2021 can't read the new kind, so Downframe won't convert a project that uses one to those versions.

What you'll see

The project is kept as it is, with the note "Uses a 2023 track matte that 2022 and older can't read". Other files in the same batch still convert. Converting the same project to 2023 or later works.

What you can do

  • If you have the newer After Effects, set those layers' Track Matte to None, rebuild them the old way (matte layer directly above), save, and drop the file in again. Downframe tells you if it still finds a layer track matte.
  • Ask whoever sent the project to do the same.
