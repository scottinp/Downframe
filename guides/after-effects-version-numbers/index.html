After Effects version numbers by year

Since 2022, the After Effects version number matches the year: 2022 is 22.x, 2026 is 26.x. Before that it didn't: 2021 is 18.x and 2020 is 17.x. There are no versions 19, 20 or 21.

Check which version you have

On Windows, choose Help → About After Effects. On a Mac, choose After Effects → About After Effects. The first number is the one in the table.

Check which version saved a file

Drop the file into the converter. It reads the version from the file and shows it, for example "Saved in After Effects 2025 (25.x)". More on this.
