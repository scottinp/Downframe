Which After Effects version saved this file?

Drop the .aep or .ffx into the converter. It reads the version from the file and shows it next to the name, for example "Saved in After Effects 2025 (25.x)". You don't need After Effects installed, and the file isn't uploaded.

How it knows

Every project and preset starts with a short header that records the version of After Effects that saved it. After Effects reads the same header when you open a file, and refuses it if the number is higher than its own.

What it can tell

  • Which year saved the file, from 2020 to 2026.
  • For projects, any third-party plugin effects they use.

If it can't tell, it says "saved in a version of After Effects that Downframe does not recognise yet".

Then what?

If the file is newer than your After Effects, pick your version in the same screen and convert it. Which year is which version number?
