01 / How it works

It changes the version stamp, not your animation.

Downframe rewrites two bytes in the header of your .ffx preset. Every other byte stays exactly as it was.

Rewrites the version

Every preset records the After Effects version that saved it. Downframe finds that record and sets it to the version you picked.

Checks the file

Before you download, it confirms the file still reads correctly and the version was actually changed.

Does not translate

Anything the older version does not understand is left as it is, so test the result in your version.
