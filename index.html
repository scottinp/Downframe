        02 / FAQ

        Questions

        After Effects says "this file was created with a newer version of After Effects — time to upgrade your application! (26 :: 280)". How do I fix it?

        The preset was saved in a newer version of After Effects than yours. Drop it into Downframe above, pick your version, and apply the converted copy instead.

        Is my file uploaded anywhere?

        No. The file is read and converted on this page, inside your browser. It is never sent to a server. The page only reports how many files were converted, for the counter, not which ones.

        My converted preset will not open. Why?

        It probably uses something the older version does not have. Changing the version stamp cannot add a missing effect or property.

        Does it work with .aep project files?

        Yes, from After Effects 2026 down to 2021, the same versions as presets. Projects saved in 2023 or later are rebuilt for 2022 and 2021, which store layers differently. One case can't be converted to 2022 or older: a layer that uses another layer as its track matte (new in 2023).

        My converted project crashes After Effects. Why?

        Most likely a third-party plugin effect (for example Sapphire or Universe). Plugins save their own data, and an older plugin version can crash instead of showing an error. Downframe lists them before you convert: disable them in the newer version first, or save your other work before opening the converted project.

        Can it convert older files to a newer version?

        You do not need a tool for that. After Effects already opens presets and projects from older versions.

        03 / Contact

        Found a preset that breaks?

        Tell me which version saved it and which one you converted to. That is how the supported list grows.
