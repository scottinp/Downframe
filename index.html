      01 / How it works

      It changes the version stamp, not your animation.

      Rewrites the version

      Every preset records the After Effects version that saved it. Downframe finds that record and sets it to the version you picked.

      Checks the file

      Before you download, it confirms the file still reads correctly and the version was actually changed. If not, you get an explanation and no file.

      Does not translate

      Anything the older version does not understand is left as it is. The preset may open with properties missing, which is why you should test every converted preset in your version.

      02 / FAQ

      Questions

      After Effects says "this file was created with a newer version of After Effects — time to upgrade your application! (26 :: 280)". How do I fix it?

      The preset was saved in a newer version of After Effects than yours. Drop it into Downframe above, pick your version, and apply the converted copy instead.

      Is my file uploaded anywhere?

      No. The file is read and converted on this page, inside your browser. It is never sent to a server. The page only reports how many files were converted, for the counter, not which ones.

      My converted preset will not open. Why?

      It probably uses something the older version does not have. Changing the version stamp cannot add a missing effect or property.

      Does it work with .aep project files?

      Not yet. Presets only for now.

      Can it convert older presets to a newer version?

      You do not need a tool for that. After Effects already opens presets from older versions.

      03 / Contact
